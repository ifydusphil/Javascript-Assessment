# JavaScript Practice Questions 💻

This repository contains solutions to beginner-friendly JavaScript questions designed to teach fundamental concepts such as conditionals, user input, comparison, switch statements, and more.

## 📚 Questions Covered

1. **Driving Age Check**
   - Prompt user for age and determine if they're old enough to drive.

2. **Age Comparison**
   - Compare your age to a fixed age and print who is older.

3. **Compare Two Numbers**
   - Use both `if...else` and ternary operator to compare two numbers.

4. **Even or Odd Check**
   - Check if a given number is even or odd using modulus `%`.

5. **Season Detector**
   - Determine the season based on the entered month using `if...else`.

6. **Working Day or Weekend**
   - Use both `if...else` and `switch` statement to check if a day is a weekend or a workday.

## 📁 Files

- `scfript.js` – Contains all solutions to the JavaScript assessment questions above.
- *(Optional)* `index.html` – For running script in a browser if needed.
